# きらめき！IDOL PROJECT

個人用のアイドル育成ブラウザゲームのプロトタイプです。

## 起動方法
- `index.html` をブラウザで開きます。
- 追加ソフトやサーバーは不要です。
- データは同じブラウザのローカルストレージに自動保存されます。

## GitHub Pagesで公開
1. GitHubで新しいリポジトリを作成します。
2. `index.html` と `README.md` をリポジトリ直下にアップロードします。
3. Settings → Pages → Deploy from a branch を選択します。
4. Branch を `main`、フォルダを `/ (root)` にして保存します。
5. 表示されたURLからゲームを開きます。

## 実装済みの主な仕様
- 40人のキャラクター設定、6衣装カテゴリ・合計240カード図鑑
- ガチャ：1時間に1枚、最大30枚、SSR 5% / SR 15% / R 30% / N 50%
- 1回ガチャ・10連ガチャ（10連確定枠なし）
- スタミナ最大100、3分ごとに1回復
- レッスン：EXP +20/30/50、スタミナ消費20/30/50
- レベル必要経験値：Lv.1→2が50、以降レベルごとに+10
- レベルアップごとに4能力の内部値が各+0.5、表示は小数点以下切り捨て
- SSR/SR/R/Nの基本レベル上限65/55/45/35
- 同一カード合成による覚醒、最大5回、1回につきレベル上限+2
- フォーメーション、カード詳細、図鑑、JSONバックアップ・復元

## 注意
これはプロトタイプです。キャラクターのプロフィールやカード絵は仮の絵文字・CSS表現です。ブラウザのデータを削除すると自動保存データも消えるため、設定画面から定期的にバックアップしてください。GitHub Pagesに公開しても個人のセーブデータがGitHubに送信されることはありません。
